# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment,
personal attacks and discrimination are not accepted in issues, pull requests, discussions or any
other project space.

## Reporting

Report unacceptable behavior to the maintainer through the contact address on the maintainer's
GitHub profile. Reports are handled confidentially. The maintainer may remove content and block
participants who break this code.
